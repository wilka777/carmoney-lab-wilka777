# Правила разработки

1. Новые или изменённые пороги, лимиты и бизнес-константы берутся из
   `backend/config/rules.php`, а не записываются числом в PHP-коде.
2. В ответе о найденном месте кода указывается путь файла и номер строки.
3. Перед изменением порога, лимита, формулы или ожидания теста запрашивается
   решение риск-менеджмента; ради зелёной проверки их не меняют.
4. Если просьба пользователя противоречит этим правилам, код не изменяется:
   агент объясняет конфликт и просит явное решение ответственного человека.
