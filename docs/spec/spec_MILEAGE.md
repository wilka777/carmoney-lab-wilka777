# Спецификация MILEAGE: учёт пробега в решении

## Входит / не входит

Входит правило, по которому пробег выше 400 000 км понижает только
потенциальное `approve` до `review`. Не входят изменение валидационного потолка,
границ LTV, API, фронтенда, базы и синтетических сидов. (ответ в интервью)

## Требования и критерии приёмки

### REQ-MILEAGE-01

При пробеге выше 400 000 км заявка, которая по LTV получила бы `approve`,
должна получить `review`. Источник: ответ в интервью.

- **AC-MILEAGE-01:** Given валидная заявка с LTV 50.0 и пробегом 399999, When
  рассчитывается решение, Then результат `approve`. Источник числа: ответ в интервью.
- **AC-MILEAGE-02:** Given валидная заявка с LTV 50.0 и пробегом 400000, When
  рассчитывается решение, Then результат `approve`. Источник числа: ответ в интервью.
- **AC-MILEAGE-03:** Given валидная заявка с LTV 50.0 и пробегом 400001, When
  рассчитывается решение, Then результат `review` и лимит равен 0. Источник
  числа: ответ в интервью.

### REQ-MILEAGE-02

Правило пробега не смягчает `reject`: решение `reject` по LTV остаётся
`reject` при любом валидном пробеге. Источник: ответ в интервью.

- **AC-MILEAGE-04:** Given валидная заявка с LTV 95.0 и пробегом 400001, When
  рассчитывается решение, Then результат `reject`. Источник чисел: ответ в интервью.

### REQ-MILEAGE-03

Отсутствующий пробег остаётся ошибкой валидации; правило пробега применяется
только после успешной текущей валидации. Источник: ответ в интервью; код:
`backend/src/Domain/ApplicationValidator.php`.

- **AC-MILEAGE-05:** Given заявка без поля пробега, When выполняется оценка,
  Then возникает `ValidationException`, а решение не рассчитывается. Источник:
  ответ в интервью; код: `backend/src/Domain/ApplicationValidator.php`.
- **AC-MILEAGE-06:** Given пробег 500001, When выполняется оценка, Then
  возникает `ValidationException`, а не `review`. Источник числа: код:
  `backend/config/rules.php`.

### REQ-MILEAGE-04

`review` из-за пробега не отличается в ответе от текущего `review` по LTV:
новые поля, причины и флаги не добавляются. Источник: ответ в интервью; код:
`backend/src/Domain/AssessmentService.php`.

- **AC-MILEAGE-07:** Given заявка с LTV 50.0 и пробегом 400001, When
  возвращается результат, Then `approved_limit` равен 0 и набор полей ответа
  не расширен. Источник числа: ответ в интервью.
