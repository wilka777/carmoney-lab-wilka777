# D2.1.1: замер токенов для поиска по пробегу

Трек: разработчик. Вопрос: «Все места, где используются `mileage` и
`max_mileage_km`: файл и функция».

| Замер | Input tokens | Output tokens | Стоимость, $ | Агент звал ast-index |
| --- | ---: | ---: | ---: | --- |
| Без индекса | 52 499 | 2 228 | 0.00984231 | нет |
| ast-index | 55 236 | 2 775 | 0.00755088 | да |

## Команды индекса

- `ast-index search mileage`
- `ast-index search max_mileage_km`

## Вывод

При прямом указании использовать `ast-index` агент вызвал индекс, а не
`grep`. Стоимость ответа снизилась с $0.00984231 до $0.00755088, хотя
входных токенов стало немного больше. Сам по себе установленный индекс не
меняет поведение модели: использование потребовало явного указания в
промпте.
