# E2E-проверка MILEAGE через Playwright

## Окружение

- Сервис поднят локально на `http://localhost:8080`, healthcheck `200`.
- Стек: `make up` (backend `Slim + PHP 8.3` на `:8080`, MySQL 8). Playwright
  не менял код и тесты.
- Фронтенд-форма открыта через Playwright из `frontend/index.html`.
- Данные синтетические, `applicant_ref` и `vin` — дефолтные из формы
  (`CL-0025`, `XTA21099998765432`).

## Сценарий 1 — пробег 400001 км

Шаги:
1. `playwright_browser_navigate` на `http://localhost:8080` — загрузилась форма
   «Предварительная оценка заявки на заём под ПТС».
2. В поле «Пробег, км» введено `400001`. Остальные обязательные поля оставлены
   дефолтными: оценочная стоимость `900000`, запрошенная сумма `450000`,
   год `2019`, срок `24`.
3. Нажата кнопка «Отправить заявку».
4. Снят скриншот всей страницы и сохранён в
   `docs/setup/e2e_mileage_400001_review.png`.

Дословный текст, который показала система в блоке «Решение»:

> Решение: review
> LTV: 50 %
> Возраст авто: 7 лет
> Одобренный лимит: 0 ₽
> Номер заявки: 27

Сценарий 1 выполнен успешно, скриншот сохранён.

## Сценарий 2 — пробег 600000 км

Шаги:
1. На той же странице в поле «Пробег, км» изменено значение на `600000`
   (остальные поля без изменений).
2. Повторно нажата кнопка «Отправить заявку».
3. Снят скриншот всей страницы и сохранён в
   `docs/setup/e2e_mileage_600000_error.png`.

Дословный текст, который показала система в блоке «Заявка не принята»:

> Заявка не принята
> mileage: Пробег от 0 до 500000 км

Блок «Решение» при этом скрыт, заявка отклонена валидатором
(`backend/src/Domain/ApplicationValidator.php:43-45`, лимит
`vehicle.max_mileage_km = 500000` в `backend/config/rules.php:23`).

Второе место, где пользователь видит правило по пробегу: блок ошибки формы
показывает дословно «Пробег от 0 до 500000 км». Первое — блок «Решение»,
где при 400001 км отображается `review`.

Сценарий 2 выполнен успешно, скриншот сохранён.

## Проверка выполнена

Сессия Playwright прошла без отказов: оба POST на `/api/applications` дошли до
бэкенда, страница отрисовала ожидаемые блоки «Решение» и «Заявка не принята».

Проверка выполнена Playwright через браузерную сессию.
